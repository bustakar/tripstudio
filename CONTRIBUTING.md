# Contributing

Thanks for helping improve Trip Studio.

## Issues

Use the issue forms for reproducible bugs and focused feature requests. For security
vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Pull requests

1. Fork the repository and create a focused branch from `main`.
2. Install Node.js 22+, pnpm 11+, and PostgreSQL.
3. Copy `.env.example` to `.env.local` and configure a local database.
4. Make the smallest coherent change and add focused tests when behavior changes.
5. Run `pnpm check`.
6. Open a pull request and explain the problem and solution.

Maintainers may close proposals that do not fit the project's scope. By contributing, you agree
that your contribution is licensed under the repository's MIT License.
